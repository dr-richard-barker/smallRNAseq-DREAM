01Status of the Plant miRNA Scan

The plant miRNA outputs in this repository are not interpretable yet. An evidence check on 2026-10-28 found three problems:

  • OSD-437 is standard poly(A) RNA-seq, not small RNA-seq. Its OSDR record lists one RNA-Seq assay (19 samples, library selection "polyA enrichment", NEB Next Ultra II RNA Library Prep Kit). OSDR holds no plant small RNA-seq.
  • The locus map mislabels most IDs. Of the 29 IDs the hand-typed map labels as MIR genes, 3 are the named MIR gene. 16 are protein-coding (for example AT1G53160 is SPL4, labelled "MIR156b"), 2 are lncRNA, 1 is snoRNA and 7 are a different MIR gene (Ensembl Plants lookup).
  • The fold changes are not flight vs ground. The scan uses the first contrast in each GeneLab table. For OSD-437 that is 1g centrifuge vs microgravity, both in flight. For OSD-120, OSD-218, OSD-565 and OSD-782 it compares ground or treatment groups. For OSD-217 it is ground vs flight, the reverse orientation.

TODO: rebuild the locus map from Ensembl Plants miRNA genes, select each study's flight-vs-ground contrast by name, then regenerate the tables and figures. Until then, no miRNA result from this scan should be cited.

02The Recommended Pipeline Route

From hands-on testing of four small RNA-seq analysis engines (nf-core/smrnaseq, sRNAtoolbox, miRDeep2, miRDeep-P2), the author recommends this route for cross-species analysis. The quantitative four-engine benchmark has not been run yet.

SRA → mirnaQC → sRNAbench → sRNAde → mirNOVO

nf-core/smrnaseq runs under Nextflow's container profiles. The original SLURM/OSDR cluster script was lost before consolidation, and the sRNAtoolbox Singularity definition is still to be added.

05Illustrative Fisher Test

For each pathway, a Fisher exact test compares the pairs whose target has P ≤ 0.05 against a typed background of 25,000 genes and 3,500 "DE" genes, assumed rather than measured, and each target is counted once per study. The p-values are therefore illustrative, not an enrichment result. TODO: use each study's measured gene universe and DE set.
